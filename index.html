Publish public catalogue Admin

Creates catalog-public.json — a safe snapshot for the public site. It includes bibliographic details, themes, pedagogy, specs, blurbs and covers. It excludes all rights, royalty, contract links, internal PDF links and distributor terms. Copy the downloaded file into your GitHub repo folder, then commit and push in GitHub Desktop. Visitors see the new catalogue within a minute.

Team & access Admin only

Superadmin manages everyone including admins. Admin can import Excel, publish the public catalogue, and invite Editors and Viewers. Editor adds and edits titles, rights and royalty. Viewer is a read-only staff login. The general public needs no account — they see the published catalogue and can generate from it.

Security in place: passwords are stored only as salted SHA-256 hashes, never as text. Five failed sign-in attempts locks sign-in for 5 minutes. Sessions expire after 8 hours (or 30 days if "keep me signed in" was ticked). Every change to the catalogue is recorded in the activity log with the user's name.
