Why Netlify? It is the simplest way to put a web app online — you literally drag a folder onto the screen. Free, reliable, used by millions of organisations. No credit card, no server to manage, nothing to install.
1
Unzip the downloaded files already done
Unzip the katha-catalogue-app.zip file. You will see a folder called katha-catalogue-app with four files inside: index.html, app.js, manifest.json, sw.js. Keep this folder open — you will drag it in step 5.
2
Create a free Netlify account
Go to netlify.com → click Sign up → choose Sign up with Email → enter an email address and password → verify your email. Takes 2 minutes.

Use Katha's main email (info@katha.org or similar) so the account belongs to the organisation, not one person.
3
Go to Sites
After logging in, click Sites in the top navigation. Scroll to the bottom of the page — you will see a large area that says:
Drag and drop your site output folder here
Leave this browser window open.
4
Drag the folder onto Netlify
Find the katha-catalogue-app folder on your computer. Drag the entire folder and drop it on that grey zone in the browser. Netlify uploads all four files. Progress bar → green tick. Takes about 20 seconds.
Common mistake: drag the folder itself, not the files inside it, and not the .zip file. If you see an error, try again with just the folder.
5
Your app is live
Netlify gives you a temporary address like cheerful-oak-a3f1c2.netlify.app. Click it. You should see the Katha login screen. Enter the default password katha@books to confirm it is working.
The app is now live. Part B connects it to books.katha.org. If you do not have DNS access today, use the Netlify address — it works identically.
This part changes one DNS record for katha.org. If Katha's website is managed by an IT partner or agency, forward them steps 2–4 only.
1
Copy your Netlify site address
In Netlify → click your site → Site configuration → Domain management. At the top is your address, e.g. cheerful-oak-a3f1c2.netlify.app. Copy it.
2
Add the custom domain in Netlify
Still in Domain management → click Add a domain → type books.katha.org → Verify → Add domain. Netlify will show "Awaiting External DNS" — that is normal, continue to the next step.
3
Add a CNAME record at your domain registrar
Log into wherever katha.org's DNS is managed — usually your domain registrar (GoDaddy, Namecheap, BigRock, Cloudflare, Hostinger) or a cPanel provided by your web host. Find DNS Management or DNS Zone Editor. Add one new record:
Type: CNAME
Name / Host: books
Value / Points to: your-netlify-address.netlify.app
TTL: 3600 (or leave default)
Save.
4
Wait — HTTPS is automatic
DNS changes take 5 minutes to 2 hours. Go back to Netlify → Domain management and watch the books.katha.org row. When a green padlock appears, Netlify has issued a free HTTPS certificate automatically. Your app is now live at https://books.katha.org.
If your domain is on Cloudflare, set the CNAME record to DNS only (grey cloud). Netlify handles HTTPS itself and the orange cloud causes a conflict.
1
Sign in with the default password
Go to books.katha.org (or your Netlify address). Enter: katha@books. Tick Keep me logged in on this device for 30 days. Click Sign in.
2
Change the password immediately
Click Data & backup → scroll to Password & access. Enter katha@books as the current password. Choose a new one (at least 8 characters). Confirm it. Click Update password.
Do this before sharing the URL with anyone. The default password is public — anyone who finds the URL and reads this guide knows it.
3
Import book details first
Still in Data & backup → Import from Excel → click Choose file → select: Katha Book details 441 titles.xlsx

Click Import file. Wait about 5 seconds. You will see: "Imported: 441 new, 0 updated". Check the Dashboard — 441 titles, English and Hindi.
4
Import the PDF links file second
Import from Excel → choose Katha All Book Master PDFs Link.xlsx → Import file. Wait about 10 seconds. The notification will say something like "Imported: 297 new, 441 updated". This adds Kannada and Tamil titles, English title mappings, ISBNs, and SharePoint PDF links. Dashboard will now show 730+ titles across 4 languages.
5
Take a backup immediately
Data & backup → click Full backup (.json). Save the file to SharePoint or Google Drive. Name it with today's date: katha-backup-2026-06-12.json.
Set a reminder to export a new backup every Friday. It takes 5 seconds. Under 1 MB for 700+ titles.
6
Review the Dashboard alerts
Click Dashboard. The Needs attention panel shows everything requiring action — Wikimedia Commons licences to verify, titles missing blurbs, titles with no rights data. Start with the Wikimedia ones: those affect what you can sell commercially.
1
Share the URL and password
Send the team the address books.katha.org and the password you just set. Everyone uses the same single password.
Keep the password private. Do not put it in a forwarded email chain or public group. A WhatsApp message to specific named people is fine.
2
Install as an app on phones and tablets
No App Store needed — installs directly from the browser.

iPhone / iPad (Safari): Open books.katha.org in Safari → tap the Share button (box with arrow pointing up) → scroll down → tap Add to Home Screen → tap Add. The Katha icon appears on the home screen. Opens full-screen.

Android (Chrome): Open books.katha.org → tap the three-dot menu → Add to Home screen → Add.

Desktop (Chrome or Edge): Click the install icon in the address bar (computer with + symbol) → Install.
After installation, the app works offline — useful at book fairs, warehouses, or anywhere without reliable internet.
3
Designate one person as the catalogue keeper
Data is stored in the browser of each device. Edits on one device do not automatically appear on another. Designate one person (and one device) as the master for editing. Others read on their own devices by restoring the keeper's JSON backup.

Workflow: Keeper edits → exports JSON backup → shares to SharePoint → others restore if they need a local offline copy.
When multiple people need to edit from different devices simultaneously, that is when to move to Airtable or a Supabase backend (Phase 2). The Excel export from this app imports directly into both with no rework.
